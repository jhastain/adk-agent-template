How It Works

Step What Happens
Clone Copy template, replace 5 tokens (agent name, service prefix, display name), rename directories
Build Agent Write tools in tools.py, instructions in prompts.py, wire into agent.py
Test Local adk web agents/ — interactive dev UI at localhost:8000
PR Pipeline runs ruff + pyright + pytest + IaC plan
Deploy Merge → IaC apply → adk deploy agent_engine → manual gates between envs
