Agent Deployment Models

Agent types and deployment patterns for ADK agents on Google Agent Engine.

Agent Types (all deploy to Agent Engine)

Five agent types — same deploy command, different agent.py structure
Type ADK Class Use When agent.py Pattern
Standard LlmAgent Single agent with tools, LLM-driven decisions root_agent = LlmAgent(tools=[...])
Coordinator LlmAgent Delegates to sub-agents based on intent root_agent = LlmAgent(sub_agents=[a, b])
Sequential SequentialAgent Fixed pipeline — each step passes state to next root_agent = SequentialAgent(sub_agents=[...])
Parallel ParallelAgent Independent tasks run concurrently root_agent = ParallelAgent(sub_agents=[...])
Loop LoopAgent Iterative refinement with exit condition root_agent = LoopAgent(sub_agents=[...], max_iterations=N)
All five deploy to Agent Engine via uv run adk deploy agent_engine --agent-engine-id={id}. Sub-agents are defined in the same agent.py file. The deploy command and pipeline are identical — only the agent.py structure changes.

Key Insight: Model 2 agents can delegate to Model 3 agents built with ANY framework (CrewAI, LangGraph, custom). The A2A protocol is the universal interface. Model 3 agents can be owned by other teams, other orgs, or external vendors — as long as they serve an Agent Card and implement the A2A protocol.

Key Differences Summary

Model 1 Standard ADK Agent
Same as both: Agent Engine deployment, Vertex AI SDK queries
Different: No delegation, no A2A protocol, simplest structure
When to use: Self-contained agents with no need to call other agents
Model 2 A2A Client (Orchestrator)
Same as Model 1: Agent Engine, ADK, gateway MCP
Different from Model 1: a2a_client.py, before_agent_callback, send_task(), remote agent URLs
When to use: Orchestrators that delegate specialized tasks to remote agents
Model 3 A2A Server (Remote Agent)
Same as both: None — completely different architecture
Different: Cloud Run, Dockerfile, no ADK, no gateway, framework-agnostic, serves Agent Card
When to use: Specialized agents that other agents call remotely, or when using non-ADK frameworks
